# To-Brew-List
To do list featuring javascript and CRUD (Create, Read, Update, and Delete)
✨ Features
📅 Smart Calendar View – See your tasks on a beautiful glassmorphism calendar with sticky-note style task pills on each day

☕ Task Brewing – Add tasks with priority (Low/Medium/High) and due dates

⏩ Snooze +1 Day – Postpone any task by one day with a single click

✅ Task Completion – Check off tasks with a satisfying animation and celebration effect

🎉 Celebration Effects – Burst of emojis when you complete a task

🔄 Drag & Drop – Reorder tasks by dragging them in the list

🎯 Filtering – View All, Active, or Completed tasks

📊 Progress Tracking – See your completion progress with a dynamic progress bar

🌙 Dark/Light Theme – Toggle between cozy dark and light modes

💾 Local Storage – All your tasks are saved automatically in your browser

⌨️ Keyboard Shortcuts – Ctrl/Cmd + K to focus the input, Escape to cancel editing

🛠️ Tech Stack
HTML5 – Semantic markup

CSS3 – Custom properties, grid, flexbox, animations, glassmorphism

JavaScript – Vanilla JS, ES6+, DOM manipulation, drag & drop
